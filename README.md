# Spotify Hit Song Analysis

## Business Question

What factors are associated with a song becoming one of Spotify's most streamed tracks in 2023?

## Tools Used

- SQL (SQLite)
- Python
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Git
- GitHub
- VS Code

## Key Findings
- Playlist exposure was strongly associated with streaming success (r = 0.79).
- Hit songs appeared in significantly more playlists than non-hit songs (p < 0.001).
- Danceability showed a statistically significant difference between hit and non-hit songs.
- Energy and valence showed no significant differences.
- Artist collaborations were not positively associated with streaming success.

## Conclusion
Playlist inclusion was the factor most strongly associated with streaming success in the Spotify 2023 dataset.
